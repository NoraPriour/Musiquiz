# Musiquiz

Musiquiz est un quiz musical interactif en français. À chaque partie, l'application sélectionne aléatoirement 10 questions parmi une banque de plus de 100 questions.

## Démo

[Jouer à Musiquiz](https://norapriour.github.io/Musiquiz/)

## Fonctionnalités

- tirage aléatoire de 10 questions ;
- validation et correction immédiate de chaque réponse ;
- calcul du score ;
- possibilité de rejouer avec un nouveau tirage ;
- interface responsive ;
- gestion d'erreur si les questions ne peuvent pas être chargées.

## Technologies

- HTML
- CSS
- JavaScript
- JSON

## Lancer le projet localement

Le projet utilise `fetch` pour charger les questions. Il doit donc être servi par un serveur HTTP local plutôt qu'ouvert directement depuis l'explorateur de fichiers.

Par exemple, avec l'extension Live Server de VS Code, ouvrez `index.html`, puis cliquez sur **Open with Live Server**.
